# RoundService

- `src/server/RoundService.luau`: `start()` is idempotent; `stop()` cancels the loop, drops connections and clears state (specs call stop+start in a beforeEach wrapper, since the runner has no hook). A `generation` counter makes a start that's still waiting give up after stop(); a failed start resets `started`. HallBuilder is required lazily. It uses the existing `Workspace.Hall` (it only builds one if missing), makes or reuses `Hall.LobbyPlatform` 30 studs above Start, and runs the loop in a task.
- Loop: Lobby 15s → spawn everyone at Start (waits up to 10s) → Running ≤120s → Ended 5s. The Lobby timer stays at 15 while the server has no players.
- LoadCharacter runs in a pcall with 3 tries. A player who still has no character is dropped from the round, so it isn't held open.
- Player attribute `InRound`: true from the round spawn until death, escape or Ended. Monster and NoiseService ignore players without it. Spectators (late joiners, dead players who respawned) are moved to the platform during Running, and during the spawn wait (`spawning` flag; RoundState is still Lobby then), plus a sweep of non-participants when Running begins.
- A `round` counter guards Died handlers, so a character from an earlier round can't mark someone dead.
- Escape: Exit.Touched sets Escaped=true before coins are added, so the reward can't be paid twice.
- `stop()` is test-only and does nothing unless started. It and a failed start() share a local `teardown()`, which also sets `platform` to nil. Test hooks are all in `RoundService._test`: `setSpawning`, `placeSpectator(player, character)`, `platform()`, `loop()`. The spec passes a plain `{ Character = model }` table as the player (a non-participant only has `.Character` read).
- Sprint 6: start() setup is split into `step(name, fn)` pcalls ("the lobby platform", "player setup", "the exit", "the round loop"). Any failure runs teardown() and errors "start() failed at <name>: ...". Extra test hooks: `_test.failStep(name)`, `_test.connectionCount()`, `_test.started()`. The spec runs resetState() (stop, clear State, destroy Hall.LobbyPlatform) before and after every test.
- Sprint 7: start() has no test branch. step() calls `RoundService._test.beforeStep(name)` (a no-op), and `_test.failStep(name)` swaps that hook. `onPlayerAdded` is defined inside the "player setup" step, and `spawnAtStart` inside "the round loop" step. The spec skips itself (`return {}`) if RoundState is Running or a player stands on Hall.LobbyPlatform. It detaches the original platform (it never destroys it) and re-parents it after each test.
- Studio gotcha: the open Studio may be synced to another checkout, not this worktree. To run worktree specs, inject the sources as temp ModuleScripts with execute_luau. The Server datamodel only exists during play-with-player, so the "no players" Lobby test returns early there.
- main.server retries any system's `start()` that errors: every 5 s, up to 5 retries. A system that started is put in `startedSystems` and is never started again.
- Gotcha: a spec can get its own module instance (separate require cache), so its `stop()` can't stop main.server's loop, and main's loop keeps writing the shared `State` attributes. Specs should check this instance's own state (e.g. `_test.loop()` being dead), not whether State stopped changing.
- Sprint 20: phase lengths live in locals `lobbyTime/runTime/endedTime` (default 15/120/5), read when each phase begins. `_test.setDurations(l, r, e)` is Studio only (errors elsewhere), each arg a finite number >= 0.5 (checked one by one: a nil in a table constructor is skipped). `_test.resetDurations()`, `_test.durations()`. Lobby/Ended count in steps of min(1, left) and write `math.ceil(left)`, so integer defaults behave exactly as before.
- Escaped is cleared when the *next* Lobby's countdown ends (round spawn), while RoundState is still Lobby, not when Lobby begins. WaterLevel is reset by NoiseService (on Lobby/Running), not RoundService.
- Running the round smoke spec in Studio: main.server's loop is a separate instance, so QA disables `ServerScriptService.Server.main` in Edit mode, plays, runs the spec in the Server datamodel, and starts NoiseService by hand to exercise the water reset; then re-enables main. The spec's `anotherLoopRunning()` skips when another loop is writing State.
- Sprint 21/22: Studio-only stand-in players live in `src/server/RoundTestPlayers.luau`, not RoundService. RoundService reads players through a `PlayerSource` (`getPlayers`, `playerFromCharacter`, `connectPlayers(onAdded, onRemoving)`, `connectExit(exit, onTouched)`); in a live game it is always `defaultSource` (Players service + Exit.Touched). `_test.setPlayerSource(src)` swaps it (Studio only; nil restores the default), `_test.usingDefaultSource()`. RoundTestPlayers: `attach(RoundService)` (errors outside Studio; call while stopped, because start() connects through the source it sees), `add(name): FakePlayer`, `touchExit(part): boolean` (false if start() hasn't connected the exit or stop() dropped it), `removeAll()`, `detach()`. It is passed the spec's RoundService instead of requiring it, because the spec may have its own module instance. A fake is a declared `FakePlayer` type backed by an unparented Folder (attributes, leaderstats.Coins = 0, CharacterAdded event), turned into a Player in one `asPlayer` helper. It calls start()'s join/leave/exit handlers only while their connection is still `.Connected`. Monster/NoiseService don't see fakes. A Studio play-test has only one real player, which is why fakes exist.
- Spec log watch (sprint 22): fails a test if RoundService warns (every warn goes through local `report()`, which calls the `_test.onWarn` hook) or if ScriptContext.Error fires with the RoundService/RoundTestPlayers ModuleScript as the script or in the stack trace. No message-text matching. Waits are `waitUntil`/`waitForState` on state changes with 5–15 s timeouts; the loop writes TimeLeft 0 and Ended in one step, so a spec never sees Running at 0.
- Known gaps (sprint 22): no test drives a real LoadCharacter failure or the spawn timeout; the Died handler is not exercised by a spec (no fake dies); Monster/NoiseService never see fakes, so the full round with the monster is untested with more than one player; the `anotherLoopRunning()` 1.25 s watch window and the "no players Lobby stays at 15" 1.5 s check are still fixed waits (they observe that nothing changes); warnings printed by another RoundService instance (main.server's) are no longer caught; the setDurations/attach "errors outside Studio" paths only run on a non-Studio server; "with no players the Lobby timer stays at 15" passes without checking anything in a Studio play-test (there's always a real player).
- Owns `leaderstats.Coins` (created on PlayerAdded). Other systems should add to it, not recreate it.
